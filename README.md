# 🚢 Maritime Technology

A ship is effectively a highly specialized remote site.

Unlike a conventional office environment, maritime technology must support business operations while simultaneously dealing with:

- Limited or variable connectivity
- Satellite WAN services
- Remote troubleshooting
- Operational technology
- Long hardware lifecycles
- Vendor-managed systems
- Cybersecurity requirements
- Remote access
- Vessel safety considerations
- Globally distributed users
- Limited opportunities for physical intervention

My work focuses on bridging these environments.
